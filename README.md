### First launch / Premier lancement

The installers are not code-signed. / Les installeurs ne sont pas signés.

- **Windows** — SmartScreen shows "Windows protected your PC": **More info ▸ Run anyway**.
  SmartScreen affiche « Windows a protégé votre ordinateur » : **Informations complémentaires ▸
  Exécuter quand même**.
- **macOS** — Gatekeeper refuses a plain double-click. Up to macOS 14: right-click the app ▸
  **Open**. From macOS 15: open the app once, then **System Settings ▸ Privacy & Security ▸ Open
  Anyway**.
  Gatekeeper refuse le simple double-clic. Jusqu'à macOS 14 : clic droit sur l'app ▸ **Ouvrir**.
  À partir de macOS 15 : ouvrir l'app une fois, puis **Réglages Système ▸ Confidentialité et
  sécurité ▸ Ouvrir quand même**.

## License / Licence

HotWire4X is free to download, install and use with no time limit to design and save projects,
configure your machine, simulate and test the movements. A license unlocks the production
features: direct USB control of the machine, and G-code display and export. The software is the
same file for everyone: activating a license needs no reinstallation.

HotWire4X se télécharge, s'installe et s'utilise gratuitement et sans limite de durée pour
concevoir et sauvegarder des projets, configurer sa machine, simuler et tester les mouvements. La
licence débloque les fonctions de production : le pilotage direct de la machine par USB,
l'affichage et l'export du G-code. Le logiciel est le même fichier pour tout le monde : activer une
licence ne demande aucune réinstallation.
